# React QR Code Generator / React QR Kód Generátor

A simple and clean QR code generator built with React and the `qrcode` library.  
Egyszerű, letisztult QR kód generátor React-ben, a `qrcode` könyvtár segítségével.

---

## Tech stack / Technológiai háttér

- **React.js (ES6+)** – component-based architecture / komponensalapú felépítés
- **qrcode** – QR code generation in SVG format / QR kód generálás SVG formátumban
- **Vite** – fast development environment / gyors fejlesztői környezet
- **HTML5 + CSS3** – responsive layout / reszponzív elrendezés

---

## Features / Funkciók

- Real-time QR code generation from text or URL  
  Valós idejű QR kód generálás szöveg vagy URL alapján
- SVG rendering and download option  
  SVG megjelenítés és letöltési lehetőség
- Clean, mobile-friendly UI  
  Letisztult, mobilbarát felület
- Safe SVG injection via `dangerouslySetInnerHTML`  
  Biztonságos SVG beágyazás `dangerouslySetInnerHTML` segítségével
